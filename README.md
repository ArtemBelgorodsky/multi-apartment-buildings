# Контур

Веб-приложение на Vue 3 для управления эксплуатацией многоквартирных домов. Данные хранятся в REST API Mokky.

## Запуск

```powershell
npm.cmd install
npm.cmd run dev
```

Открой адрес из вывода Vite. Команда `npm.cmd run build` собирает приложение в `dist`.

## Настройка Mokky

По умолчанию приложение использует `https://3e7d823b5c12a32d.mokky.dev`. Для другого проекта задай `VITE_MOKKY_URL` в `.env.local`.

В настройках Mokky включи аутентификацию, регистрацию и загрузку файлов. Приложение обращается к `/auth`, `/register`, `/auth_me` и `/uploads`. Аккаунты хранятся в `/users`.

| Ресурс | Содержимое |
| --- | --- |
| `/buildings` | Реестр домов |
| `/premises` | Квартиры и помещения |
| `/systems` | Инженерные системы |
| `/employees` | Сотрудники |
| `/crews` | Эксплуатационные бригады |
| `/tickets` | Заявки, сроки, материалы и история |
| `/maintenance` | Регламентные работы |
| `/incidents` | Журнал аварий |
| `/materials` | Номенклатура и начальный остаток |
| `/stock_moves` | Приход и расход материалов |
| `/users` | Аккаунты и роли |

Поля `code`, `buildingCode` и другие поля с суффиксом `Code` связывают записи. Новый житель выбирает дом при создании заявки. Для привязки профиля укажи `buildingCode` и `premiseCode` в `/users`. Email специалиста должен совпадать с его email в `/employees`.

Роли `admin`, `dispatcher`, `specialist` и `resident` назначаются в Mokky. Ограничения по роли и записи применяются в интерфейсе Vue. Для работы с реальными данными жителей нужна серверная проверка прав на операции и записи.

JWT сессии и отметки о прочтении уведомлений хранятся в браузере. Реестры и фотографии загружаются из Mokky.
